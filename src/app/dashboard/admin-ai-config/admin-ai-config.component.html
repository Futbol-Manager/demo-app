Fórmula de créditos
créditos consumidos = créditos_base(modelo) × multiplicador_tokens

El crédito base refleja el coste relativo del modelo. El multiplicador penaliza las consultas largas (mucho contexto, plantillas completas...). El mínimo siempre es 1 crédito.
