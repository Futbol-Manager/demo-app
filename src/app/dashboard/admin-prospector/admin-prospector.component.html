Meta — Instagram & Facebook
{{ socialTokens['meta_access_token'] ? 'Conectado ✓' : 'Sin conectar' }}
  1. Ve a developers.facebook.com/apps y crea o selecciona tu app.
  2. Activa el producto Instagram Graph API y conecta tu cuenta Business.
  3. En Graph API Explorer genera un User Access Token con permisos instagram_basic, instagram_content_publish, pages_manage_posts, pages_read_engagement.
  4. Conviértelo en Long-Lived Token (60 días) desde Graph API Explorer → Info → Extend.
  5. Copia tu Instagram Business Account ID (Settings → Instagram → IG User ID) y tu Facebook Page ID (About del Page).
LinkedIn
{{ socialTokens['linkedin_access_token'] ? 'Conectado ✓' : 'Sin conectar' }}
  1. Ve a LinkedIn Developers → Crear app. Necesitas una LinkedIn Page de empresa.
  2. En tu app, ve a Products y solicita Share on LinkedIn y Sign In with LinkedIn.
  3. En Auth, añade como Redirect URL: https://www.linkedin.com/developers/tools/oauth/redirect
  4. Ve a OAuth 2.0 Token Generator, selecciona tu app y los scopes w_member_social, r_liteprofile. Genera el token.
  5. Para el Author URN: llama a GET https://api.linkedin.com/v2/me con el token y copia el campo id → el URN es urn:li:person:TU_ID
urn:
Ejemplo: urn:li:person:AbCdEfGhIj. Para páginas de empresa: urn:li:organization:1234567
X / Twitter
{{ socialTokens['twitter_api_key'] ? 'Conectado ✓' : 'Sin conectar' }}
  1. Ve a developer.twitter.com y crea una cuenta de desarrollador (requiere descripción del uso).
  2. Crea un Project y dentro una App. Solicita acceso Elevated (gratis) para poder publicar tweets.
  3. En tu App → Keys and Tokens: genera y copia API Key y API Key Secret.
  4. En la misma pantalla, genera Access Token y Access Token Secret con permisos de lectura y escritura.
  5. En Settings → App permissions, asegúrate de que está en Read and Write.
